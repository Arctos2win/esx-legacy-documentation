# Welcome to the ESX Documentation
ESX is the ultimate framework for building immersive and extendable servers for FiveM.

## What is ESX?
ESX is the leading open-source framework for FiveM, and has been for a long time and has thus been in development for 5+ years! 
It is the most feature-rich framework and is used by many of the biggest servers in the FiveM community.

<br/>

We are:
- **Open Source**: ESX is open source and free to use for everyone.
- **Community Driven**: ESX is developed by the community for the community.
- **Feature Rich**: ESX is the most feature-rich framework for FiveM.
