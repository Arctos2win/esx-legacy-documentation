# Welcome to ESX: Legacy
ESX: Legacy is the ultimate framework for building immersive and extendable servers for FiveM.

## What is ESX?
ESX is a long-standing non-profit organization that provides free and open-source projects for the FiveM community. Our flagship project, ESX: Legacy, is a framework for building roleplay servers in FiveM. Legacy is designed to be easy to use and highly customizable, allowing server owners to create unique and engaging experiences for their players.

<br/>

We are:
- **Open Source**: ESX is open source and free to use for everyone.
- **Community Driven**: ESX is developed by the community for the community.
- **Feature Rich**: ESX is the most feature-rich framework for FiveM.
