# esx_notify
The notification system used by `es_extended`

**Arguments**
- message: `string`
- The notification message.
- type: `string`
- The notification type
- length: `number`
- The progressbar options

**Notification Types**
- success
- error
- info

## Client Triggers

### ESX Function

**Example**
```lua
ESX.ShowNotification('This is my new test.', 'error', 1500) 
```

### Export

**Example**
```lua
exports['esx_notify']:Notify('error', 'This is my new test.',  1500) 
```

## Server Triggers

**Example**
```lua
TriggerClientEvent("esx:showNotification", playerId, "This is my new test.", "error", 1500)
```
