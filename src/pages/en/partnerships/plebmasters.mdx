## Forge Integration for ESX

Forge by **Pleb Masters** is a comprehensive GTA V modding data and tool browser. It provides quick access to object hashes, animations, props, vehicles, textures, and more - useful when scripting for ESX resources.

[Visit Forge](https://forge.plebmasters.de/)

## What is Forge?

Forge offers:

- Browsable GTA V game data: objects, vehicles, peds, clothes, animations, etc.
- Tools like Flags Generator, GXT Resolver, JOaat Hash Converter, and a 3D Tattoo Editor

This guide shows how ESX developers can efficiently use these resources in their scripts.

## Using Forge Data in ESX

ESX scripting often needs:

- Object/prop hashes for spawning items
- Animation names for player actions
- Vehicle identifiers or model names

Forge helps you find these without trial-and-error.

### Example: Using an Object Hash

```lua
local objectName = "prop_ld_flow_bottle" -- lookup on Forge
local coords = GetEntityCoords(PlayerPedId())

ESX.Game.SpawnObject(objectName, coords, nil, false)
```

## 👕 Durty Cloth Tool

<img src="https://imgur.com/wHosvgI.png" alt="Durty Cloth Tool Logo" />

The **Durty Cloth Tool** is a powerful and user‑friendly application for creating and managing GTA V addon clothing and tattoo packs. It supports **FiveM, alt:V, RageMP, and singleplayer**, and is designed to make cloth modding easier regardless of your experience level.

### 🎨 Key Features

- **3D Clothing Preview:** Visualize clothes in 3D before exporting.
- **Cloth & Tattoo Support:** Build both clothing and tattoo resources with game‑compatible options.
- **Texture Optimization:** Optimize textures for performance without quality loss.
- **Quality Reports:** Get detailed analysis and feedback on your cloth projects.
- **Cross‑Platform:** Works with multiplayer mods and singleplayer setups alike.

Durty Cloth Tool is well‑regarded in the community for streamlining the process of creating GTA V cloth packs, reducing the time and effort needed to manage clothing assets for servers and mods.

For more information and documentation, visit the official site at https://gta.clothing/.
