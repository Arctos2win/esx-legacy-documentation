## dead
Is the player dead

**Server Example**
```lua
local xPlayer = ESX.GetPlayerFromId(source)
if xPlayer.dead then
    print("Player is dead")
else
    print("Player is alive")
end
```

**Client Example**
```lua 
if ESX.PlayerData.dead then
    print("Player is dead")
else
    print("Player is alive")
end
```
