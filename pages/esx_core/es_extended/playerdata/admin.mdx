## admin
If the player is an admin.

<Callout type="warning">
    When used on the clientside, should not be the only thing you check for player's permission. 
    When triggering things on the serverside make sure to check for player's permission there too.
</Callout>

**Example**
```lua 
if ESX.PlayerData.admin then
    print("Player is admin")
end
```
