## job
The player's job `table`.

<Callout type="warning">
    When used on the clientside, should not be the only thing you check for player's job. 
    When triggering things on the serverside make sure to check for player's job there too.
</Callout>

**Values**
<OutputTable isTable={true} rows={[
    { arg: "id", type: "number", description: "The job's id from the database" },
    { arg: "name", type: "string", description: "The job's name" },
    { arg: "label", type: "string", description: "The job's label" },
    { arg: "grade", type: "string", description: "The job's grade" },
    { arg: "grade_name", type: "string", description: "The job's grade name" },
    { arg: "grade_label", type: "string", description: "The job's grade label" },
    { arg: "grade_salary", type: "string", description: "The job's grade salary" },
    { arg: "skin_male", type: "table", description: "The job's male grade skin/outfit" },
    { arg: "skin_female", type: "table", description: "The job's female grade skin/outfit" },
]}/>

**Example**
```lua 
if ESX.PlayerData.job.name == "police" then
    print("Player is a police officer")
    renderMarkers()
end
```
