## group
The player's group. (e.g. admin, user, vip)

<Callout type="warning">
    This should not be the only thing you check for player's permission. 
    When triggering things on the serverside make sure to check for player's permission there too.
</Callout>

**Example**
```lua 
if ESX.PlayerData.group == "admin" then
    print("Player is an admin")
end
```
