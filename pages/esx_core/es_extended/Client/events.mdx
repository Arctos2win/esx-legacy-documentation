# Clientsided Events
This page is dedicated to the client events introduced by the esx_core scripts.

## Triggered by the Client
The events listed here are triggered by the client.

### esx:playerPedChanged
This is a listen only event and should not be triggered. This event gets triggered when the player's ped id changed.

**Returns**
<OutputTable rows={[
    { arg: "ped", type: "number", description: "The player's new ped entity handle" },
]}/>

**Example**
```lua 
AddEventHandler('esx:playerPedChanged', function(ped)
    print("Player ped has changed and now has the ped id: "..ped)
    print("The player also has: ".. GetEntityHealth(ped))
end)
```

### esx:playerJumping
This is a listen only event and should not be triggered. This event gets triggered when the player jumps.

**Example**
```lua 
AddEventHandler('esx:playerJumping', function()
    print("The player is jumping")
end)
```

### esx:enteringVehicle
This is a listen only event and should not be triggered. This event gets triggered when the player is entering a vehicle.

**Returns**
<OutputTable rows={[
    { arg: "vehicle", type: "number", description: "The vehicle's entity handle." },
    { arg: "plate", type: "string", description: "The vehicle's plate." },
    { arg: "seat", type: "number", description: "The seat the player is entering." },
    { arg: "netId", type: "number", description: "The vehicle's net id." },
]}/>

**Example**
```lua 
AddEventHandler('esx:enteringVehicle', function(vehicle, plate, seat, netId)
    local engineHealth = GetVehicleEngineHealth(vehicle)
    print("Player is entering a vehicle with the plate: " .. plate .. "and with the engine health " .. engineHealth)
end)
```

### esx:enteringVehicleAborted
This is a listen only event and should not be triggered. This event gets triggered when the player has stopped entering a vehicle.

**Example**
```lua 
AddEventHandler('esx:enteringVehicleAborted', function()
    print("Player has stopped entering vehicle")
end)
```

### esx:enteredVehicle
This is a listen only event and should not be triggered. This event gets triggered when the player has succesfully entered a vehicle.

**Returns**
<OutputTable rows={[
    { arg: "vehicle", type: "number", description: "The vehicle's entity handle." },
    { arg: "plate", type: "string", description: "The vehicle's plate." },
    { arg: "seat", type: "number", description: "The seat the player has entered." },
    { arg: "displayName", type: "string", description: "The vehicle's display name." },
    { arg: "netId", type: "number", description: "The vehicle's net id." },
]}/>

**Example**
```lua 
AddEventHandler('esx:enteredVehicle', function(vehicle, plate, seat, displayName, netId)
    local engineHealth = GetVehicleEngineHealth(vehicle)
    print("Player has entered a " .. displayName .. " with the engine health " .. engineHealth)
end)
```

### esx:exitedVehicle
This is a listen only event and should not be triggered. This event gets triggered when the player has exited a vehicle.

**Returns**
<OutputTable rows={[
    { arg: "vehicle", type: "number", description: "The vehicle's entity handle." },
    { arg: "plate", type: "string", description: "The vehicle's plate." },
    { arg: "seat", type: "number", description: "The seat the player has exited out of." },
    { arg: "displayName", type: "string", description: "The vehicle's display name." },
    { arg: "netId", type: "number", description: "The vehicle's net id." },
]}/>

**Example**
```lua 
AddEventHandler('esx:exitedVehicle', function(vehicle, plate, seat, displayName, netId)
    print("Player has exited an " .. displayName .. " from the seat with the index: " .. seat)
end)
```

### esx:updateWeaponAmmo
This is a trigger only event. Can be used to update weapon ammo.

**Arguments**
<ArgumentsTable rows={[
    { arg: "weaponName", type: "string", description: "The weapon name." },
    { arg: "ammoCount", type: "number", description: "The new weapon's ammo count." },
]}/>

**Example**
```lua
TriggerServerEvent('esx:updateWeaponAmmo', "weapon_pistol", 100)
```

### esx:useItem
This is a trigger only event. Can be used to force a player to use a item. This will trigger `ESX.UseItem` on the serverside.

**Arguments**
<ArgumentsTable rows={[
    { arg: "itemName", type: "string", description: "The item that got removed." },
]}/>

**Example**
```lua 
TriggerServerEvent('esx:useItem', "bread") -- Eat a bread
```

### esx:pauseMenuActive
This is a listen only event and should not be triggered. This event gets triggered when the player opens or closes the pause menu.

**Returns**
<OutputTable rows={[
    { arg: "active", type: "boolean", description: "Is pause menu active." },
]}/>

**Example**
```lua
AddEventHandler('esx:pauseMenuActive', function(isActive)
	print(string.format(('pause menu stat is: %s'), isActive)) 
end)
```


## Triggered by the Server
The events listed here are triggered by the server.

### esx:addInventoryItem
This is a listen only event and should not be triggered. This event gets triggered when the player has received an item.

**Returns**
<OutputTable rows={[
    { arg: "itemName", type: "string", description: "The vehicle's entity handle." },
    { arg: "itemCount", type: "number", description: "The vehicle's plate." },
]}/>

**Example**
```lua 
RegisterNetEvent('esx:addInventoryItem', function(item, count)
  print(string.format(('You have received %sx %s'), count, item))
end)
```
