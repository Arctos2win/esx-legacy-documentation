# Client Events

This section contains the client sided events 

## esx:addInventoryItem

```lua
RegisterNetEvent('esx:addInventoryItem', function(item, count) end)
```

This event is triggered when the player has received an item

| Argument | Type   | Explanation |
| -------- | ------ | ----------- |
| item     | string | item name   |
| count    | number |             |

Example:

```lua
RegisterNetEvent('esx:addInventoryItem', function(item, count)
  print(string.format(('You have received %sx %s'), count, item))
end)
```

## esx:pauseMenuActive

```lua
AddEventHandler('esx:pauseMenuActive', function(isActive) end)
```

<Callout type = "info" emoji = "ℹ️">
Available from this version: [1.9.1](https://github.com/esx-framework/esx_core/releases/tag/1.9.1)
</Callout>

This event is triggered when the player toggle pause menu

Example:

```lua
AddEventHandler('esx:pauseMenuActive', function(isActive)
	print(string.format(('pause menu stat is: %s'), isActive)) 
end)
```

## showAdvancedNotification

```lua
TriggerClientEvent('esx:showAdvancedNotification', source, title, subject, msg, icon, iconType)
```

This event shows a notification for the specified source. This is what you'll want to use server side when you want to send a notification.

<Callout type = "info" emoji = "ℹ️">
Do not use this event for client side, instead use [ESX.ShowAdvancedNotification](functions/notification#showadvancednotification)
</Callout>


Example:

```lua
TriggerClientEvent('esx:showAdvancedNotification', source, 'title', 'subject', 'msg', 'CHAR_AMMUNATION', 3)
```

## showHelpNotification

```lua
TriggerClientEvent('esx:showHelpNotification', source, msg)
```

This event shows a help notification with the parsed message. These help notification support displaying button inputs, see [this list](https://pastebin.com/HPg8pYwi)

<Callout type = "info" emoji = "ℹ️">
Do not use this event for client side, instead use [ESX.ShowHelpNotification](functions/notification#showhelpnotification)
</Callout>

Example:

```lua
TriggerClientEvent('esx:showHelpNotification', source, 'Hit ~INPUT_CONTEXT~ to do shit!')
```

## showNotification

```lua
TriggerClientEvent('esx:showNotification', source, 'Hello world!', 'info', time)
```

This event shows a basic notification to the player. This is what you'll want to use server side when you wan to send a notification.

| Argument | Data Type | Optional | Default Value | Explanation                               |
| -------- | --------- | -------- | ------------- | ----------------------------------------- |
| msg      | string    | No       | -             | The message to display                    |
| time     | number    | Yes      | 3000          | For how long the notification should show |
| Type     | string    | Yes      | "info"        | What type the notification would be       |

**String Types**

| Syntax    | Types                |
| --------- | -------------------- |
| "info"    | Info Notification    |
| "success" | Success Notification |
| "error"   | Error Notification   |

**Color Codes**

```lua
~r~ = Red
~b~ = Blue
~g~ = Green
~y~ = Yellow
~p~ = Purple
~c~ = Grey
~m~ = Dark Grey
~u~ = Black
~o~ = Orange
```
<Callout type = "info" emoji = "ℹ️">
Do not use this event for client side, instead use [ESX.ShowNotification](functions/notification#shownotification)
</Callout>
