# Player Data

You can retrieve and manipulate the PlayerData class client side with these functions.

The PlayerData class contains the main informations about the character.

## GetPlayerData

```lua
ESX.GetPlayerData()
```

This function gets player data.

## SetPlayerData

```lua
ESX.SetPlayerData(key, val)
```

This function sets player data, this can Then be access with `ESX.PlayerData[key]`

Example:

```lua

-- Setting the value
ESX.SetPlayerData('IsArrested', false)

-- This can then be accessed wih:
ESX.PlayerData.IsArrested
```

## accounts

```lua
ESX.PlayerData.accounts
```
Default accounts:
- Bank: the money deposited in the bank account
- Money: the cash money of the player
- Black: the "dirty money" of the player

## coords

```lua
ESX.PlayerData.coords
```

This function returns a table of the players current coords

## dateofbirth

```lua
ESX.PlayerData.dateofbirth
```

This function returns the date of birth of the player. in a MM/DD/Y format
