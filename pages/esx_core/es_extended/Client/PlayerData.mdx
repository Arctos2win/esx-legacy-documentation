# Client Player Data
Data of the player, can be used to get data about the player.

## PlayerLoaded
This variable returns a `bool` if the player's character has finished loading.

**Example**
```lua 
CreateThread(function()
    while not ESX.PlayerLoaded do
        Wait(1000)
        print("Player has not laoded")
    end
end)
```


## PlayerData

### coords
The player's last known coords and heading.

<OutputTable isTable={true} rows={[
    { arg: "x", type: "number", description: "The players coords on the x axis." },
    { arg: "y", type: "number", description: "The players coords on the y axis." },
    { arg: "z", type: "number", description: "The players coords on the z axis." },
    { arg: "heading", type: "number", description: "The players heading." },
]}/>

**Example**
```lua 
if #(ESX.PlayerData.coords - vector3(124, 152, 26)) < 5 then
    print("Player is in the range of 5 meters!")
end
```

### ped
The player's ped handle.

**Example**
```lua
local playerHealth = GetEntityHealth(ESX.PlayerData.ped) 
print("player has " .. playerHealth .. " hp")
```

### group
The player's group. (e.g. admin, user, vip)

<Callout type="warning">
    This should not be the only thing you check for player's permission. 
    When triggering things on the serverside make sure to check for player's permission there too.
</Callout>

**Example**
```lua 
if ESX.PlayerData.group == "admin" then
    print("Player is an admin")
end
```

### identifier
The player's rockstar identifier.

**Example**
```lua 
print("The player's identifier is: " .. ESX.PlayerData.identifier)
```

**Values**
<OutputTable isTable={true} rows={[

    { arg: "usable", type: "boolean", description: "Does the item have a use callback?" },
    { arg: "rare", type: "boolean", description: "Is the item rare?" },

**Example**

