# Game functions

This section contains all gameplay related client functions

## GetPedMugshot 
this function takes a mugshot from given ped

**Returns**

The ped mugshot and txd
<OutputTable rows={[
    { arg: "mugshot", type: "string", description: "the mugshot" },
    { arg: "txd", type: "string", description: "the mugshot txd"}
]}/>

**Arguments** 
<ArgumentsTable rows={[
    { arg: "ped", type: "ped object", description: "the ped you want a mugshot from." }, 
    { arg: 'transparent', type:'boolean', optional: true, defaultValue: 'false', description: 'if the picture needs to be transparent or not'} 
]} />

**Example** 
```lua
local ped = PlayerPedId() 
local mugshot, txd = ESX.Game.GetPedMugshot(ped, true)
```

## Teleport 
this function teleports given entity to given coords 

**Arguments**
<ArgumentsTable rows={[
    { arg: "entity", type: "entity handle", description: "the entity to teleport." }, 
    { arg: 'coords', type:'vector3', description: 'the coords the entity needs to be teleported to.'}, 
    { arg: 'cb', type:'function', optional: true, description: 'the callback function that will be triggered after.'} 
]} />

**Example** 

```lua
local entity = PlayerPedId() 

ESX.Game.Teleport(entity, vector3(0,0,0), function() 
      print('player is teleported') 
end)
```

## SpawnObject 
this function will spawn an object

**Arguments**
<ArgumentsTable rows={[
    { arg: "model", type: "string or hash", description: "the model name or hash of the object" }, 
    { arg: 'coords', type:'vector3', description: 'where the object needs to be spawned'}, 
    { arg: 'cb', type:'function', description: 'the callback function'}, 
    { arg: 'networked', type:'boolean', description: 'if the object needs to be networked or not'}
]} />

**Example** 

```lua
local coords = GetEntityCoords(PlayerPedId()) 
ESX.Game.SpawnObject('prop_tool_bluepnt', coords, function() 
  print('object is spawned') 
end, true)
```
