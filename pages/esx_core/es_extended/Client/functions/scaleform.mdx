# Scaleform functions

This section contains all scaleform related client functions

## RequestScaleformMovie

```lua
ESX.Scaleform.Utils.RequestScaleformMovie(movie)
```

This function requests and returns a scaleform handle for the movie parsed.

| Argument | Data Type | Optional | Default Value | Explanation                                                                       |
| -------- | --------- | -------- | ------------- | --------------------------------------------------------------------------------- |
| movie    | string    | No       | -             | The movie name, [list of avilable scaleforms](https://scaleform.devtesting.pizza) |

Example:

```lua
local scaleform = ESX.ScaleForm.Utils.RequestScaleformMovie('MP_BIG_MESSAGE_FREEMODE')
```

## ShowBreakingNews

```lua
ESX.Scaleform.ShowBreakingNews(title, msg, bottom, sec)
```

This function shows the 'Breaking News' scaleform used multiple times in the campaign.

| Argument | Data Type | Optional | Default Value | Explanation                        |
| -------- | --------- | -------- | ------------- | ---------------------------------- |
| title    | string    | No       | -             | Title text                         |
| msg      | string    | No       | -             | Message text, supports HTML syntax |
| bottom   | string    | No       | -             | Footer text, supports HTML syntax  |
| sec      | number    | No       | -             | Time in seconds to show scaleform  |

## ShowFreemodeMessage

```lua
ESX.Scaleform.ShowFreemodeMessage(title, msg, sec)
```

This function displays a freemode message for the player.

| Argument | Data Type | Optional | Default Value | Explanation                       |
| -------- | --------- | -------- | ------------- | --------------------------------- |
| title    | string    | No       | -             | Title text                        |
| msg      | string    | No       | -             | Message text                      |
| sec      | number    | No       | -             | Time in seconds to show scaleform |

Example:

```lua
ESX.Scaleform.ShowFreemodeMessage('~o~fact of the day', '~y~Hawaii is a king', 5)
```
