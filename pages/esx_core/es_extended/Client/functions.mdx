## HideUI 
this function will hide the textui

**Example** 

```lua
local interactCoords = vector3(0, 0, 0)
CreateThread(function()
    local TextUI
    while true do
        local coords = GetEntityCoords(PlayerPedId())
        local inDist = #(coords - interactCoords) < 2.0
        if inDist and not TextUI then 
            ESX.TextUI('Press [E] to interact')
        elseif inDist and TextUI then 
            ESX.HideUI() 
        end
        Wait(500)
    end 
end) 
```

## ShowAdvancedNotification
this function will show a notification 

**Arguments** 
<ArgumentsTable rows={[
    { arg: "sender", type: "string", description: "the notification title." }, 
    { arg: 'subject', type:'string', description: 'the notification subtitle'},
    { arg: 'msg', type: 'string', description: 'the notification message'}, 
    { arg: 'textureDict', type: 'string', description: 'the texture dictionary for the icon'}, 
    { arg: 'iconType', type: 'string', description: 'the icon type, see the list below.'}, 
    { arg: 'flash', type: 'boolean', optional: true, defaultValue: 'false', description: 'According to the fivem natives, this var never works no matter what.'},  
    { arg: 'saveToBrief', type: 'boolean', description: 'Makes the notification appear in the "Pause Menu > Info/Brief > Notifications" section.'}, 
    { arg: 'hudColorIndex', type: 'number', optional: true, description: 'the background color for the notification.'}
]} />

**Icon types**

* 1 : Chat Box  
* 2 : Email  
* 3 : Add Friend Request  
* 4 : Nothing  
* 5 : Nothing  
* 6 : Nothing  
* 7 : Right Jumping Arrow  
* 8 : RP Icon  
* 9 : $ Icon 

**Hud color indexes**

* 6 : red 
* 184 : green 
* 190 : yellow 

**Example** 

```lua
local handle = RegisterPedheadshot(PlayerPedId())
while not IsPedheadshotReady(handle) or not IsPedheadshotValid(handle) do
    Wait(0)
end
local txd = GetPedheadshotTxdString(handle)
local title = GetPlayerName(PlayerId())
local subtitle = "Private Message"
local iconType = 0
ESX.ShowAdvancedNotification(title, subtitle, 'this is the message that we send to you', txd, iconType, false, true, 6)
```
