# Functions

The following are ESX Client sided Functions

## IsPlayerLoaded
```lua
ESX.IsPlayerLoaded()
```

This functions returns if the player is loaded

Example:
```lua
while not ESX.IsPlayerLoaded() do Wait(250) end 
```

## Progressbar

```lua
ESX.Progressbar(message, lenght, options)
```
This function shows a progress bar and execute code on finish and/or on cancel .

<ArgumentsTable rows={[
    { arg: "message", type: "string", optional: false, explanation: "The message to display" },
    { arg: "lenght", type: "int", optional: false, explanation: "the duration in ms"}, 
    { arg: "options", type:"table", optional: true, explanation: "Options"}
]} />

Example:

* ESX Function
```lua
    ESX.Progressbar("Unlocking Storage", 3000,{
        FreezePlayer = true, 
        animation ={
            type = "anim",
            dict = "anim@mp_player_intmenu@key_fob@", 
            lib ="fob_click"
        },
        --[[ Scenario can be used
        animation ={
        type = "Scenario",
        Scenario = "PROP_HUMAN_BUM_BIN", 
        },]]
        onFinish = function()
        --Code here
    end, onCancel = function()
        --Code here
    end
    })
```

* Export
  
```lua
    exports["esx_progressbar"]:Progressbar("Unlocking Storage", 3000,{
        FreezePlayer = true, 
        animation ={
            type = "anim",
            dict = "anim@mp_player_intmenu@key_fob@", 
            lib ="fob_click"
        },
        onFinish = function()
        --Code here
    end})
```
## SearchInventory

```lua
ESX.SearchInventory(items, count)
```

This function search inventory for the specified item(s) and count.

| Argument  | Data Type | Explanation                                                          |
|-----------|-----------|----------------------------------------------------------------------|
| item      | string    | The item to search for                                               |
| count     | int       | the quantity of the item                                             |

Example:

```lua
 CreateThread( function()
    while true do
        Wait(2000)
        if checkItem('bread') then
            print('I just ate some bread')
        else 
            print('I have no more bread')
        end
    end    
end)

function checkItem(item)
  local hasItem = ESX.SearchInventory(item, 1)
    if hasItem >= 1 then
        return true
    else
        return false
    end
end
```

## TriggerServerCallback

```lua
ESX.TriggerServerCallback(name, cb, args)
```

This function triggers a server callback. See [ESX.RegisterServerCallback](./../../server/functions/registerservercallback) on registering server callbacks.

| Argument | Data Type | Optional | Default Value | Explanation                                                                                                                                                         |
| -------- | --------- | -------- | ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| name     | string    | No       | -             | A valid server callback name                                                                                                                                        |
| cb       | function  | No       | -             | The returned function when the async task has completed. The invoked function a varied size of arguments depending on how many arguments are parsed from the server |
| args     | any       | Yes      | -             | Any arguments to parse to the async function                                                                                                                        |

<Callout type="warning" emoji="⚠️">
  The code inside the server callback run asynchronously.
</Callout>

Example:

```lua
local myAgument = 'hello'

RegisterCommand('testcb', function()
    ESX.TriggerServerCallback('mycallback', function(haveItem)
        if haveItem then  --This code is async
            print('Callback succesfull - i have bread')
        end
    end, 'bread')
end)

-- This code is sync
```
