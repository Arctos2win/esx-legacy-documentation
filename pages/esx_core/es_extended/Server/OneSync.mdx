## GetPlayersInArea

this function gets all players in the given area. 

<ArgumentsTable rows={[
    { arg: "playerId", type: "int", optional: false, explanation: "The id from the player you want the near players from" },
    { arg: "radius", type: "int", optional: true, defaultValue: '100', explanation: "The radius to search for players" },
    { arg: "ignore", type: "table", optional: true, explanation: "A table with server id's that can be ignored" },
]} />

Usage: 

```lua
local this = ESX.OneSync.GetPlayersInArea(1, 10.0, {
    [1] = true 
})
    
for i=1, #this do
    local player = this[i] 
    
end 
```

in this case local table player will contain:

| id | ped object | coords | dist |
| -------- | --------- | -------- | ------------- |
| number  | string    | vector3       | number             | 

## GetClosestPlayer

this function returns the closest player from the given player 

<ArgumentsTable rows={[
    { arg: "playerId", type: "int", optional: false, explanation: "The id from the player you want the nearest player from" },
    { arg: "radius", type: "int", optional: true, defaultValue: '100', explanation: "The radius to search for the nearest player" },
    { arg: "ignore", type: "table", optional: true, explanation: "A table with server id's as keys that can be ignored" },
]} />

Example: 

```lua
local player = ESX.OneSync.GetClosestPlayer(1, 10.0, {
    [2] = true 
})
```

this function will return an empty table if no player is found. 
If a player is found it will return this: 

| id | ped object | coords | dist |
| -------- | --------- | -------- | ------------- |
| number  | string    | vector3       | number             |  

## SpawnVehicle 

this function will spawn a vehicle with the vehicle server setter, which means 
the vehicle will belong to the server and won't be removed when no clients are active. 

<ArgumentsTable rows={[
    { arg: "model", type: "string", optional: false, explanation: "The model that you want to spawn" },
    { arg: "coords", type: "int", optional: false, explanation: "the coords where you want the vehicle to spawn" },
    { arg: "heading", type: "int", optional: false, explanation: "the heading you want the vehicle to spawn with" },
    { arg: "properties", type: "table", optional: false, explanation: "the vehicle properties"}, 
    { arg: "cb", type: "function", optional: false, explanation: "the callback function"}
]} />

<Callout type="warning">
    When there is no player in a radius of 300 from the coords, the vehicle will NOT spawn. 
</Callout>

Example: 

```lua
ESX.OneSync.SpawnVehicle('blista', vector3(0, 0, 0), 0, {}, function(networkId)     
    local vehicle = NetworkGetEntityFromNetworkId(networkId)
end)  
```

## SpawnPedInVehicle 

this function will spawn a ped inside a vehicle 

<ArgumentsTable rows={[
    { arg: "model", type: "string", optional: false, explanation: "The model that you want to spawn" },
    { arg: "vehicle", type: "vehicle handle", optional: false, explanation: "the vehicle handle the ped needs to be spawned in" },
    { arg: "seat", type: "number", optional: false, explanation: "the seat where the ped needs to be spawned in" },
    { arg: "cb", type: "function", optional: false, explanation: "the callback function"}
]} />

Example: 

```lua
local vehicles = GetAllVehicles()

if #vehicles < 1 then return end 
ESX.OneSync.SpawnPedInVehicle('a_f_m_beach_01', vehicles[math.random(1, #vehicles)], -1, function(networkId)
    local ped = NetworkGetEntityFromNetworkId(networkId) 
end)
```

## GetPedsInArea 

this function will get all peds in given area ( coords + radius ) 

<ArgumentsTable rows={[
    { arg: "coords", type: "vector3", optional: false, explanation: "The coords of the area" },
    { arg: "radius", type: "int", optional: false, explanation: "the radius of the area" },
    { arg: "modelFilter", type: "table", optional: false, explanation: "a table with models that have to be filtered" },
]} />

this function will return a table with the network id's from the found peds

Example: 

```lua
local peds = ESX.OneSync.GetPedsInArea(vector3(0,0,0), 30.0, {
    [joaat('a_f_m_beach_01')] = true -- joaat is a function of lua v5.4
})

for i=1, #peds do 
    local ped = NetworkGetEntityFromNetworkId[peds[i]] 
end 
```
