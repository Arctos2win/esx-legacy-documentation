# Serversided Events
This page is dedicated to the server events introduced by the esx_core scripts.

## Triggered by the Client
The events listed here are triggered by the client and should be handled with caution.

### esx:playerPedChanged
This is a listen only event and should not be triggered. This event gets triggered when the player's ped id changed.

**Returns**
<OutputTable rows={[
    { arg: "pedNetId", type: "number", description: "The player's new ped Net Id." },
]}/>

**Example**
```lua 
RegisterNetEvent('esx:playerPedChanged', function(pedNetId)
    print("Player " .. source .. "'s ped has changed and now has the net id: " .. pedNetId)
end)
```

### esx:playerJumping
This is a listen only event and should not be triggered. This event gets triggered when the player jumps.

**Example**
```lua 
RegisterNetEvent('esx:playerJumping', function()
    print("Player " .. source .. " is jumping")
end)
```

### esx:enteringVehicle
This is a listen only event and should not be triggered. This event gets triggered when the player is entering a vehicle.

**Returns**
<OutputTable rows={[
    { arg: "plate", type: "string", description: "The vehicle's plate." },
    { arg: "seat", type: "number", description: "The seat the player is entering." },
    { arg: "netId", type: "number", description: "The vehicle's net id." },
]}/>

**Example**
```lua 
RegisterNetEvent('esx:enteringVehicle', function(plate, seat, netId)
    print("Player " .. source .. " is entering a vehicle with the plate: " .. plate)
end)
```

### esx:enteringVehicleAborted
This is a listen only event and should not be triggered. This event gets triggered when the player has stopped entering a vehicle.

**Example**
```lua 
RegisterNetEvent('esx:enteringVehicleAborted', function()
    print("Player " .. source .. " has stopped entering vehicle")
end)
```

### esx:enteredVehicle
This is a listen only event and should not be triggered. This event gets triggered when the player has succesfully entered a vehicle.

**Returns**
<OutputTable rows={[
    { arg: "plate", type: "string", description: "The vehicle's plate." },
    { arg: "seat", type: "number", description: "The seat the player has entered." },
    { arg: "displayName", type: "string", description: "The vehicle's display name." },
    { arg: "netId", type: "number", description: "The vehicle's net id." },
]}/>

**Example**
```lua 
RegisterNetEvent('esx:enteredVehicle', function(plate, seat, displayName, netId)
    print("Player " .. source .. " has entered an " .. displayName)
end)
```

### esx:exitedVehicle
This is a listen only event and should not be triggered. This event gets triggered when the player has exited a vehicle.

**Returns**
<OutputTable rows={[
    { arg: "plate", type: "string", description: "The vehicle's plate." },
    { arg: "seat", type: "number", description: "The seat the player has exited out of." },
    { arg: "displayName", type: "string", description: "The vehicle's display name." },
    { arg: "netId", type: "number", description: "The vehicle's net id." },
]}/>

**Example**
```lua 
RegisterNetEvent('esx:exitedVehicle', function(plate, seat, displayName, netId)
    print("Player " .. source .. " has exited an " .. displayName .. " from the seat with the index: " .. seat)
end)
```

### esx:updateWeaponAmmo
This is a listen only event and should not be triggered from the serverside. Can be used to update weapon ammo or listen to ammo updates.

**Returns**
<OutputTable rows={[
    { arg: "weaponName", type: "string", description: "The weapon name." },
    { arg: "ammoCount", type: "number", description: "The new weapon's ammo count." },
]}/>

**Example**
```lua 
RegisterNetEvent('esx:updateWeaponAmmo', function(weaponName, ammoCount)
    print("Player " .. source .. "'s " .. weaponName .. " new ammo count is: " .. ammoCount)
end)
```

### esx:onAddInventoryItem
This is a listen only event and should not be triggered. Gets triggered when an inventory item gets added.

**Returns**
<OutputTable rows={[
    { arg: "source", type: "number", description: "The player source." },
    { arg: "itemName", type: "string", description: "The item that got added." },
    { arg: "itemCount", type: "number", description: "The amount the player now has." },
]}/>

**Example**
```lua 
AddEventHandler('esx:onAddInventoryItem', function(source, itemName, itemCount)
    local xPlayer = ESX.GetPlayerFromId(source)
    print(xPlayer.getName() .. " received " .. itemName .. " and now has " .. itemCount)
end)
```

### esx:onRemoveInventoryItem
This is a listen only event and should not be triggered. Gets triggered when an inventory item gets removed.

**Returns**
<OutputTable rows={[
    { arg: "source", type: "number", description: "The player source." },
    { arg: "itemName", type: "string", description: "The item that got removed." },
    { arg: "itemCount", type: "number", description: "The amount the player now has." },
]}/>

**Example**
```lua 
AddEventHandler('esx:onRemoveInventoryItem', function(source, itemName, itemCount)
    local xPlayer = ESX.GetPlayerFromId(source)
    print(xPlayer.getName() .. " lost some " .. itemName .. " and now has " .. itemCount)
end)
```

This event gets triggered when the player has successfully loaded / the character was chosen and loaded.

```lua
AddEventHandler('esx:playerLoaded', function (playerId, xPlayer)
    print(xPlayer.getName() .. " successfully loaded with the playerId: " .. playerId)
end)
```
