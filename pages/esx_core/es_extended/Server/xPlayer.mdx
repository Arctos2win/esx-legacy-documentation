## triggerEvent 
This function will trigger a client side event for the player.

**Arguments**
<ArgumentsTable rows={[
    { arg: "eventName", type: "string", description: "The event you want to trigger for the xPlayer" },
    { arg: "...", type: "arguments", optional: true, description: "All arguments that you want to send"}
]} />

**Example**

You can use more arguments like you would do in a classic TriggerEvent 
```lua 
local xPlayer = ESX.GetPlayerFromId(playerId) 

xPlayer.triggerEvent('esx:showNotification', 'this is a notification', 'error', 4000) 
```



## setCoords 
This function will change the coords of the player. Making him teleport.

**Arguments**
<ArgumentsTable rows={[
    { arg: "coords", type: "vector3 | vector4 | table", description: "The coords the player needs to be teleported to" },
]} />

**Example**
```lua
local xPlayer = ESX.GetPlayerFromId(playerId) 

xPlayer.setCoords(vector3(0, 0, 0)) 
```

## getAccounts
This function returns all of the player's accounts.

**Arguments**
<ArgumentsTable rows={[
    { arg: "minimal", type: "boolean", optional: true, description: "Should only return amount of accounts." }
]} />

**Returns**

A **`table`** with the key being the account name and the value either being a table or a number with the accounts balance amount when minimal.

Non-Minimal:
<OutputTable isTable={true} rows={[
    { arg: "name", type: "string", description: "The account name" },
    { arg: "money", type: "number", description: "The account balance" },
    { arg: "label", type: "string", description: "The account label" },
]}/>

Minimal:
<OutputTable rows={[
    { arg: "money", type: "number", description: "The account balance" }
]}/>

**Example**
```lua
local xPlayer = ESX.GetPlayerFromId(playerId)
local accounts = xPlayer.getAccounts()
local accountsMinimal = xPlayer.getAccounts(true) -- Minimal data

print("Player has " .. accounts["bank"].money .. " on his " .. accounts["bank"].name .. " account.")
print("Player has " .. accounts["black_money"] .. "on his black_money account") 
```

## getInventory
This function returns the inventory of the player.

**Arguments**
<ArgumentsTable rows={[
    { arg: "minimal", type: "boolean", optional: true, description: "Should only return count of items." }
]} />

**Returns**

A **`table`** with the key being the item name and the value either being a table or a number with the item count when minimal.
Non-Minimal:
<OutputTable isTable={true} rows={[
    { arg: "name", type: "string", description: "The item name" },
    { arg: "count", type: "number", description: "The item count" },
    { arg: "label", type: "string", description: "The item label" },
    { arg: "weight", type: "number", description: "The item weight" },
    { arg: "usable", type: "boolean", description: "Does the item have a use callback?" },
    { arg: "rare", type: "boolean", description: "Is the item rare?" },
    { arg: "canRemove", type: "boolean", description: "Can the item be removed?" }
]}/>

Minimal:
<OutputTable rows={[
    { arg: "count", type: "number", description: "The item count" }
]}/>

**Example**
```lua
local xPlayer = ESX.GetPlayerFromId(playerId)
local inventory = xPlayer.getInventory()
local breadItem = inventory["bread"]

print("Player has " .. breadItem.count .. " bread. Weighing: " .. breadItem.weight)
```
