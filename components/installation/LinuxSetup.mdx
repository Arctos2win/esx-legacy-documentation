### Installing and Setting up the Database
1. We currently don't provide a tutorial on how to setup a MySql/MariaDB database.

### Installing the Server
1. Go to your home folder and create a new folder and call it whatever you want.
1. Now go to the FiveM [Artifact Downloads page](https://runtime.fivem.net/artifacts/fivem/build_proot_linux/master/)
2. Download the most recent artifact version, [see here](https://i.imgur.com/OMcCVIW.png) for an example. You can use `wget <url>` with the artifact downlaod as a command in the terminal.
3. Now with the newly downlaoded `fx.tar.xz` in your folder run the command `tar xf fx.tar.xz`. This will unpack your server files.
4. Now you should have a `run.sh` and a `alpine` folder. You then run the command `screen -S fivem ./run.sh` to start your server in a seperate screen. You can exit the screen safely with CTRL + A + D and kill the server with CTRL + C.
5. Once started, it will give you an ip adress and a 4-digit code. You open the ip adress in your browser and put the code into the input field. Continue and log in using your [cfx.re forum](https://forum.cfx.re/) account.
7. Then it should ask you for a password. Make sure this password is secure as this is one of the options on how you will log in into your txAdmin master account.
